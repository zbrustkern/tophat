# Permanent Work Factors

## Architectural Review & Planning Archive
Whenever a new feature set is being planned (and a new `implementation_plan.md` artifact is being created), you MUST first archive the contents of the existing `implementation_plan.md` into a separate `architectural_review.md` artifact (or similar persistent documentation). This ensures that previous architectural decisions and planning history are not lost by simply overwriting the implementation plan document.

## CI/CD & Version Control
As you make changes to tests or implement CI/CD workflows, ensure that you are consistently committing and pushing those changes to the GitHub repository using git commands. This keeps the remote repository up-to-date with your local development progress.
